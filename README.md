## 🚀 How to View & Run the Website

### Option 1: Instant 1-Click Preview (Zero Setup Required)
You can view the portfolio immediately in any web browser!
1. Open your folder: `C:\Users\u\Desktop\WEBSITE\PORTFOLIO\`
2. Double-click **`index.html`**
3. It will instantly launch in Google Chrome, Microsoft Edge, or your default browser with all animations, icons, and styling active!

---

### Option 2: Run with Next.js (Full React Development Server)

If you have Node.js installed, you can run the full Next.js App Router application:

1. Open a terminal / command prompt in this folder (`c:\Users\u\Desktop\WEBSITE\PORTFOLIO`):
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
